# Glide 1.0.0 — Public Tester Release Notes

**Glide — Browse light. Stream smooth.**

Glide 1.0 is the first public tester release of the Windows browser.

## Highlights

- WebView2-based Windows browser
- lightweight logical-tab architecture
- bounded-memory engine recycling
- optional 1–4 live background tabs
- Stream Mode for gaming/streaming workloads
- OBS Studio and Meld Studio detection
- Streamer Controls
- Panic Silence and media controls
- Twitch raid handling
- bookmarks, history and downloads
- privacy/site-data controls
- popup handling
- configurable themes and accents
- session restore
- default-browser registration
- external links open in a new tab in the existing Glide window
- optional performance bar, hidden by default

## Public testing focus

For this release, feedback is especially useful around:

- long-running memory behaviour
- Twitch and YouTube playback
- multiple live tabs
- OBS/Meld workflows
- Windows display scaling
- external-link/default-browser behaviour
- downloads
- sleep/minimize/restore behaviour

## Known distribution note

The Glide 1.0 tester installer is currently unsigned, so Microsoft Defender SmartScreen may warn that the publisher is unknown.

Use the SHA-256 hashes in `SHA256SUMS.txt` to verify the files you downloaded from the official release.
